# Money Tracker

แอปบันทึกรายรับ-รายจ่ายส่วนตัว สร้างด้วย Next.js (App Router) + Supabase (ฐานข้อมูล + ระบบล็อกอิน) + Tailwind CSS ใช้งานได้ทั้งบนมือถือ (ติดตั้งเป็น PWA ได้) และคอมพิวเตอร์

## ฟีเจอร์

- บันทึกรายรับ/รายจ่ายแบบรวดเร็ว แยกหมวดหมู่ (ปรับแต่งหมวดหมู่เองได้)
- ดูรายการรายวัน และสรุปรายเดือน (รายรับเทียบรายจ่าย + กราฟสัดส่วนหมวดหมู่)
- ตั้งวงเงินงบประมาณรายเดือนต่อหมวดหมู่ พร้อมแจ้งเตือนเมื่อใกล้/เกินวงเงิน (70% / 100%)
- ดูแนวโน้มย้อนหลัง 6/12 เดือน เปรียบเทียบรายรับ-รายจ่าย
- ข้อมูลเก็บบนคลาวด์ (Supabase) เข้าถึงได้จากหลายเครื่อง ป้องกันด้วยอีเมล/รหัสผ่าน
- ออกแบบไว้สำหรับผู้ใช้คนเดียว: ไม่มีหน้าสมัครสมาชิกเปิดสาธารณะ สร้างบัญชีของคุณเองผ่าน Supabase Dashboard (ขั้นตอนด้านล่าง)

## ก่อนเริ่ม: สิ่งที่คุณต้องทำเอง (ครั้งเดียว)

โค้ดทั้งหมดเตรียมไว้ให้แล้ว แต่การเชื่อมต่อฐานข้อมูลจริงและ deploy ขึ้นเว็บ ต้องใช้บัญชีของคุณเอง (ฟรีทั้งคู่ ใช้เวลารวม ~10-15 นาที)

### 1. สร้างโปรเจกต์ Supabase

1. ไปที่ [supabase.com](https://supabase.com) สมัคร/ล็อกอิน แล้วกด **New project**
2. ตั้งชื่อโปรเจกต์และรหัสผ่านฐานข้อมูล (เก็บรหัสนี้ไว้ ไม่ต้องใช้ในแอป แต่เผื่อจำเป็น)
3. รอสักครู่จนโปรเจกต์พร้อมใช้งาน

### 2. รันสคีมาฐานข้อมูล

1. ในหน้าโปรเจกต์ Supabase ไปที่เมนู **SQL Editor** → **New query**
2. เปิดไฟล์ [`supabase/schema.sql`](./supabase/schema.sql) ในโปรเจกต์นี้ คัดลอกทั้งหมดไปวาง แล้วกด **Run**
3. สคีมานี้จะสร้างตาราง, Row Level Security (ป้องกันไม่ให้บัญชีอื่นเห็นข้อมูลของกัน), และหมวดหมู่เริ่มต้นภาษาไทยที่จะถูกสร้างอัตโนมัติให้ผู้ใช้ใหม่ทุกคน

### 3. คัดลอกค่า API

1. ไปที่ **Project Settings → API**
2. คัดลอก **Project URL** และ **anon public key** (คีย์นี้ปลอดภัยที่จะใช้ฝั่ง client เพราะออกแบบมาให้เป็น public key — ต่างจาก `service_role` key ที่ต้องเก็บเป็นความลับและไม่ใช้ในโปรเจกต์นี้)

### 4. สร้างบัญชีผู้ใช้ของคุณเอง

แอปนี้ไม่มีหน้าสมัครสมาชิกเปิดสาธารณะ (ตั้งใจให้ใช้คนเดียว) สร้างบัญชีของคุณโดยตรงใน Supabase แทน:

1. ไปที่ **Authentication → Users** → **Add user** → **Create new user**
2. ใส่อีเมลและรหัสผ่านที่จะใช้ล็อกอิน แล้วเปิด **Auto Confirm User** (จะได้ไม่ต้องกดยืนยันอีเมล)
3. กด **Create user**

ถ้าภายหลังอยากเปิดให้คนอื่นสมัครเองได้ ค่อยเพิ่มหน้า `/signup` กลับมาทีหลังได้

### 5. ตั้งค่าไฟล์ environment

คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ค่าจากขั้นตอนที่ 3:

```bash
cp .env.example .env.local
```

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key
```

### 6. รันในเครื่องเพื่อทดสอบ

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 → ล็อกอินด้วยอีเมล/รหัสผ่านที่สร้างไว้ในขั้นตอนที่ 4 → เริ่มบันทึกรายการได้เลย (ล็อกอินครั้งเดียว session จะจำไว้ในเครื่อง/มือถือ ไม่ต้องล็อกอินซ้ำทุกครั้ง)

### 7. Deploy ขึ้น Vercel

1. สร้างบัญชี [Vercel](https://vercel.com) (ฟรี) และเชื่อมกับ GitHub
2. Push โปรเจกต์นี้ขึ้น GitHub repository ใหม่
3. ใน Vercel กด **New Project** แล้วเลือก repository นี้
4. ในหน้า **Environment Variables** ใส่ `NEXT_PUBLIC_SUPABASE_URL` และ `NEXT_PUBLIC_SUPABASE_ANON_KEY` ค่าเดียวกับใน `.env.local`
5. กด **Deploy** รอสักครู่ก็จะได้ลิงก์เว็บของคุณเอง
6. เปิดลิงก์จากมือถือ แล้วเลือก "เพิ่มไปที่หน้าจอโฮม" (Add to Home Screen) เพื่อใช้งานเหมือนแอป

## โครงสร้างโปรเจกต์

```
app/(auth)/          หน้าล็อกอิน
app/(app)/           หน้าหลักหลังล็อกอิน (บันทึก, รายวัน, รายเดือน, งบประมาณ, เทรนด์, หมวดหมู่)
components/          UI components แยกตามฟีเจอร์
lib/supabase/        ตัวช่วยเชื่อมต่อ Supabase (client/server/session refresh)
lib/queries/         ฟังก์ชันอ่านข้อมูล (Server Components)
lib/actions/         Server Actions สำหรับบันทึก/แก้ไข/ลบข้อมูล
lib/utils/           ฟอร์แมตเงินบาท, วันที่ไทย, เกณฑ์งบประมาณ
supabase/schema.sql  สคีมาฐานข้อมูล + Row Level Security
proxy.ts             รีเฟรช session ของ Supabase (เทียบเท่า middleware ใน Next.js รุ่นก่อนหน้า)
```

## คำสั่งที่ใช้บ่อย

```bash
npm run dev      # รันเซิร์ฟเวอร์พัฒนา
npm run build    # build สำหรับ production
npm run lint     # ตรวจโค้ดด้วย ESLint
```
